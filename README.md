Internship Management Website

Project Overview
The Internship Management Website provides a structured workspace where interns can:
* Create an account and log in
* View their internship dashboard
* Manage assigned tasks
* Track task progress
* Submit completed tasks and projects
* View submission history
* Monitor project progress
* Manage their profile information
* Receive application notifications
* Log out securely

Features
Authentication

* User registration
* User login
* Email validation
* Password validation
* Password visibility toggle
* Password strength indicator
* Logout functionality
* Authentication-based page protection

Dashboard
The dashboard provides an overview of the intern's current activity.
It includes:
* Total assigned tasks
* Completed tasks
* Pending tasks
* Total submissions
* Overall project progress
* Recent task activity
* Project progress overview

Task Management
Interns can manage their assigned tasks through a dedicated task section.
Features include:
* Task listing
* Task categories
* Task priority
* Task status
* Due dates
* Task descriptions
* Task search
* Status filtering
* Category filtering
* Task submission navigation

Task Submission

Interns can submit completed work through the submission form.

Submission information includes:

* Task title
* Task description
* Project/work link
* Submission date
* Submission status
* Feedback

Submission statuses include:

* Under Review
* Approved
* Rejected

Project Management

The project section provides an overview of internship projects.

Each project displays:

* Project name
* Project type
* Description
* Current progress
* Project status
* Deadline

Profile Management

Interns can manage their personal information.

Profile fields include:

* Full name
* Email
* Phone number
* University
* Department
* Bio
* Skills

Profile changes are stored locally in the browser.

Notifications

The application includes a basic notification system for important activities such as successful task submissions.
